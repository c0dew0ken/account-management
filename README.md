# Account Management

Веб-приложение для управления учетными записями с валидацией и сохранением в localStorage.

## Технологии

- **Vue.js 3** - Composition API
- **TypeScript** - типизация
- **Pinia** - стейт менеджер
- **Vuetify 3** - Material Design UI
- **Vite** - сборщик

## Функциональность

- ✅ **Добавление/удаление** учетных записей
- ✅ **Валидация** полей в реальном времени
- ✅ **Автосохранение** в localStorage
- ✅ **Два типа** записей: LDAP и Локальная
- ✅ **Метки** с разделителем `;`
- ✅ **Адаптивный** дизайн

## Установка и запуск

```bash
# Установка
npm install

# Запуск dev-сервера
npm run dev

# Сборка
npm run build
```

## Структура

```
src/
├── components/     # Vue компоненты
├── stores/         # Pinia store
├── composables/    # Переиспользуемая логика
├── utils/          # Утилиты
├── types/          # TypeScript типы
├── constants/      # Константы
└── assets/         # Стили и ресурсы
```

## Хранение

Данные сохраняются в `localStorage` под ключом `accounts_storage`.

## Валидация

- **Логин**: обязательное, до 100 символов
- **Пароль**: обязательное для "Локальная", до 100 символов  
- **Метки**: необязательное, до 50 символов
